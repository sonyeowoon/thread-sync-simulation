# Thread Sync Simulation

여러 실행 흐름이 제한된 공유 자원을 함께 사용할 때의 동기화를 다루는 C 학습 프로젝트입니다. 식사하는 철학자 문제를 모델로 각 작업의 식사·수면·대기 상태와 종료 조건을 관리합니다.

## 주요 구현

- POSIX 스레드를 통한 작업 실행
- mutex를 사용한 공유 자원 접근 제어
- 마지막 식사 시각과 식사 횟수 관리
- 생존 시간과 식사 횟수에 따른 종료 상태 확인
- 상태 출력과 시간 계산, 자원 정리

## 기술

C, POSIX Threads, mutex, 공유 상태 동기화, 시간 기반 상태 관리, Make

## 빌드와 실행

POSIX 스레드를 지원하는 C 개발 환경과 Make가 필요합니다.

```sh
cd philo
make
./philo 5 800 200 200 5
```

인자는 작업 수, 생존 제한 시간, 식사 시간, 수면 시간, 선택적 식사 횟수 순서입니다. 시간 단위는 밀리초입니다. 기존 실행 파일 이름 `philo`를 유지합니다.

## 코드 안내

| 파일 | 내용 |
| --- | --- |
| `philo/philo.c` | 인자 검사와 초기화·실행·정리 흐름 |
| `philo/philo_threading.c` | 스레드 실행 관리 |
| `philo/philosopher_routine.c` | 자원 획득과 식사·수면 상태 처리 |
| `philo/philo_timestamp.c` | 시간 관련 처리 |

## 범위

동시성과 공유 자원 관리 개념을 실습하는 시뮬레이션입니다. 운영체제 스케줄링에 따라 실행 순서와 출력 시각이 달라질 수 있습니다. 모든 조건에서 교착 상태나 데이터 경쟁이 없음을 검증한 것으로 해석하지 않아야 하며, 경계 입력·반복 실행·동시성 검사 도구를 통한 검증은 별도입니다.
